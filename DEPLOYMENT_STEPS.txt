STEP 3: DEPLOY ON VERCEL (5 minutes)
================================================================================

A. CREATE VERCEL ACCOUNT (if you don't have one)
   1. Go to https://vercel.com
   2. Click "Sign Up"
   3. Choose "Continue with GitHub"
   4. Authorize Vercel to access your GitHub

B. IMPORT PROJECT
   1. In Vercel Dashboard, click "Add New Project"
   2. Find and select your GitHub repo: madhesh-kk/mayura-console-
   3. Click "Import"

C. CONFIGURE BUILD SETTINGS
   Look for these fields and fill them in:

   Framework Preset: Vite
   Root Directory: (leave blank)
   
   Build Command: 
   pnpm --filter @workspace/shop-bridge run build
   
   Output Directory: 
   artifacts/shop-bridge/dist/public
   
   Install Command: (leave default or empty)

D. ADD ENVIRONMENT VARIABLES
   Click "Environment Variables" section
   
   Add this variable:
   
   Key: VITE_API_URL
   Value: [PASTE YOUR RENDER API URL HERE]
   
   Example: https://api-dapptkt2abc123.onrender.com

E. DEPLOY
   Click the blue "Deploy" button
   
   Wait 2-3 minutes for deployment to complete
   
   You'll see: "Congratulations! Your deployment is ready"

================================================================================
TROUBLESHOOTING
================================================================================

ERROR: "Business ID verification is unavailable"
→ Fix: Your API URL is wrong
→ Action: Go to Vercel Project Settings → Environment Variables
→ Update VITE_API_URL to correct Render URL
→ Redeploy

ERROR: Build failed
→ Check: Vercel Dashboard → Deployments → Failed deployment → Logs
→ Look for: Build command, dependencies, or missing files

ERROR: Page is blank
→ Fix: Output directory is wrong
→ Verify in Vercel: artifacts/shop-bridge/dist/public

ERROR: API not responding
→ Check: Is your Render API still running?
→ Test: Visit https://your-render-api.onrender.com/api/healthz
→ Should return 200 OK
